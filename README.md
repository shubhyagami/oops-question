## Overview

This repository provides ready‑to‑compile Java programs that solve common TCS IPA exercises. Each solution demonstrates a specific OOP concept—encapsulation, inheritance, polymorphism, or abstraction—while handling edge cases and requiring no external dependencies.

## Key Features

- **OOP‑Centric** – Each example highlights a core object‑oriented principle.
- **Zero Dependencies** – Pure standard Java; no third‑party libraries needed.
- **Robust Edge‑Case Handling** – Logic guards against empty collections, null inputs, and boundary values.
- **Self‑Contained Files** – Every `.java` file can be compiled and run independently.
- **Clean Code Practices** – Meaningful naming, minimal coupling, and clear documentation.

## Getting Started

1. **Install JDK** – Ensure the Java Development Kit (JDK 8 or newer) is installed.  
2. **Clone the Repository**  
   ```bash
   git clone https://github.com/shubhyagami/oops-question.git
   ```  
3. **Compile and Run** – Navigate into the project and compile a specific solution, then execute it:  
   ```bash
   cd oops-question
   javac Question1.java
   java Question1
   ```

## Contributing

Contributions are welcome. Follow these steps:

1. **Create a Branch** – Work on a new branch rather than directly on `main`.  
   ```bash
   git checkout -b feature/your-new-addition
   ```  
2. **Compile and Test** – Verify that your code compiles without warnings and passes basic tests.  
   ```bash
   javac YourQuestion.java && java YourQuestion
   ```  
3. **Open a Pull Request** – Provide a concise description of the changes. Reviewers will assess the submission; approved PRs will be merged.

### Contribution Guidelines

- Keep PRs focused on OOP concepts and IPA‑related problems.  
- Use only standard Java APIs.  
- Review your code for proper variable scope, access modifiers, and efficiency before submitting.  

## Tips for TCS IPA

- **Read the problem statement thoroughly** before writing any code.  
- **Plan your design**—identify classes, responsibilities, and relationships.  
- **Write clear, readable code** with expressive variable names and consistent formatting.
