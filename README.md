## Overview

This repository contains self‑contained Java programs that solve common TCS IPA exercises. Every `.java` file can be compiled and run independently, showcasing clean OOP design without external dependencies.

## Key Features

- **OOP‑Centric** – Each example highlights a core object‑oriented principle.
- **Zero Dependencies** – Pure standard Java; no third‑party libraries needed.
- **Robust Edge‑Case Handling** – Guarded against empty collections, null inputs, and boundary values.
- **Self‑Contained Files** – Compile and run each solution separately.
- **Clean Code Practices** – Meaningful naming, minimal coupling, and clear documentation.

## Getting Started

1. **Install JDK** – JDK 8 or newer must be installed.
2. **Clone the Repository**  
   ```bash
   git clone https://github.com/shubhyagami/oops-question.git
   ```
3. **Compile and Run a Solution** – For example, to run `Question1.java`:  
   ```bash
   cd oops-question
   javac Question1.java
   java Question1
   ```

## Contributing

Contributions are welcome.

1. **Create a Branch** – Work on a new branch rather than directly on `main`.  
   ```bash
   git checkout -b feature/your-addition
   ```
2. **Compile and Test** – Verify that your code compiles without warnings and runs as expected.  
   ```bash
   javac YourQuestion.java && java YourQuestion
   ```
3. **Open a Pull Request** – Include a concise description of the changes. Reviewers will assess the submission; approved PRs will be merged.

### Contribution Guidelines

- Keep PRs focused on OOP concepts and IPA‑related problems.
- Use only standard Java APIs.
- Review your code for proper variable scope, access modifiers, and efficiency before submitting.

## Tips for TCS IPA

- Read the problem statement thoroughly before writing code.
- Plan your design—identify classes, responsibilities, and relationships.
- Write clear, readable code with expressive variable names and consistent formatting.
